title: Landal NL Inventory
---

A map of the components and page templates on landal.nl, the Dutch site of Landal GreenParks. It covers 77 captured pages, chosen to show every page type the site declares for itself, and the reusable components found on them.

<!-- stat-blocks -->

Each component has an example image cropped from a real page and a list of the pages that use it. Each page entry shows the full screenshot and the components it is built from, top to bottom.
